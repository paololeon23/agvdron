dronAGV — Solo HTML, CSS y JavaScript
=====================================

Sin Node.js ni npm. Abre index.html directamente.

Archivos:
  index.html  → doble clic para abrir
  styles.css  → diseño
  app.js      → lógica
  assets/     → imagen de fondo (opcional)

Uso:
1. Abre index.html en Chrome o Edge
2. Llena los valores del controlador
3. Guardar inspección → animación del dron + barra de progreso
4. Inspecciones de hoy (10 por página) → toca una tarjeta para ver detalle
5. Botón Excel → descarga .xlsx con todas las columnas del formulario (requiere internet)

Los datos se guardan en este navegador (localStorage).
